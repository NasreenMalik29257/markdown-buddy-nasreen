# Monthly Sales Analysis in R

## Overview

This project demonstrates a basic monthly sales analysis using R and a synthetic dataset. The purpose is to organize sales data, calculate descriptive statistics, and visualize monthly sales trends.

## Project Objectives

- Create a synthetic monthly sales dataset.
- Analyze monthly sales using R.
- Calculate total and average sales.
- Visualize sales using a bar chart.
- Document the analysis using R Markdown.

## Project Files

- `README.md` - Project overview and instructions.
- `monthly_sales.R` - R script for sales analysis.
- `monthly_sales.Rmd` - R Markdown documentation.
- `Reflection.md` - Reflection answers about AI-assisted documentation.
- `AI_Appendix.md` - AI prompts, responses, and verification notes.

## Dataset

The project uses fictional monthly sales values for January through June. All figures are synthetic and created for educational purposes.

## Installation

1. Install R and RStudio or use Posit Cloud.
2. Open the R project.
3. Run `monthly_sales.R`.
4. Open `monthly_sales.Rmd` and knit it to HTML.

## Example Code

