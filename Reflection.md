## Question 1: How did AI help with creating and formatting your R project documentation?

ChatGPT helped me prepare a clear structure for documenting my Monthly Sales Analysis project in R. It suggested useful README sections such as Overview, Installation, Example Code, and License. It also helped organize my R Markdown document with separate sections for inputs, data preparation, summary statistics, visualization, and outputs. ## Question 2: What benefits and limitations did you notice when using AI for Markdown documentation?

One benefit of AI was that it provided a starting point for writing documentation and organizing information. It helped me understand how headings, bullet points, and R code blocks should be presented. However, I learned that AI-generated content should not be accepted without checking it. For example, code examples and descriptions need to match the actual project, and calculations should be verified independently. AI is helpful for drafting, but I remain responsible for the final work.

## Question 3: Why is validation and responsible AI use important in data science documentation?

Validation is important because other people may depend on technical documentation to understand or reproduce an analysis. Incorrect instructions or calculations can make a project difficult to use. For my monthly sales project, I can check the README formatting on GitHub, run the R script in Posit Cloud, and compare the sales calculations with an independent manual check. Responsible AI use also means recording the AI tools and prompts, avoiding private data, and reviewing the final content for accuracy.
